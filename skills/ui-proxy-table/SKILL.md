# UI Proxy Table

## Когда использовать

- Реализация основного экрана «Прокси».
- Добавление сортировки, фильтров, пагинации, выбора.
- Копирование, экспорт.

## Принципы

- Никаких `@tanstack/react-table` и `@tanstack/react-virtual`.
  Таблица лёгкая, своя: сортируемые заголовки + серверная пагинация.
- Сортировка и фильтрация выполняются **на бэкенде** (`GetProxies` +
  `CountProxies`), фронтенд держит одну страницу.
- Копирование — **через Go** (`app.Clipboard.SetText`), не `navigator.clipboard`.

## Библиотеки

- `lucide-react` — иконки.
- shadcn/ui: `Table`, `Checkbox`, `DropdownMenu`, `Button`, `Input`, `Badge`.
- Свой компонент тостов (без `sonner`).
- Относительное время — `Intl.RelativeTimeFormat` (без `date-fns`).

## Колонки

| Ключ          | Отображение                                                   |
|---------------|---------------------------------------------------------------|
| `select`      | Checkbox                                                      |
| `host`        | Текст, `font-mono`                                            |
| `port`        | Число                                                         |
| `protocol`    | Badge (`http` / `socks5`)                                     |
| `latency`     | Badge: зелёный < 150, жёлтый 150–500, красный > 500, серый `—`|
| `download`    | `X.X Mbps` или `—`                                            |
| `lastChecked` | Относительное время (`Intl.RelativeTimeFormat`)               |
| `actions`     | DropdownMenu (Копировать, Проверить, Удалить)                 |

## Серверная пагинация

- Состояние: `page`, `pageSize` (например, 100).
- Запрос: `GetProxies({...filter, limit: pageSize, offset: page * pageSize})`.
- Общее число строк: `CountProxies(filter)` — отдельный вызов.
- Под таблицей: «Всего N», выбор размера страницы, «Назад/Вперёд».
- Смена фильтра или сортировки сбрасывает `page` на 0.
- Виртуализация не нужна (страница небольшая).

## Выбор строк

- Множественный выбор чекбоксами; Shift-клик — диапазон, Ctrl/Cmd-клик — точечно.
- Шапка: checkbox «выбрать все на странице».
- Выбранные ID хранятся отдельно от текущей страницы и не сбрасываются
  при перелистывании.

## Копирование в буфер

```ts
// Копирование делает Go-биндинг, чтобы работало в WebView на GNOME/KDE
await ProxyService.CopyToClipboard(ids, copyFormat) // copyFormat: 'uri' | 'hostport'
toast.success(`Скопировано: ${ids.length}`)
```

Формат `uri` — `protocol://host:port`, `hostport` — `host:port`.

## Повторная проверка

- «Проверить выбранные» — `TestLatencyBatch(ids)`.
- «Проверить нерабочие» — фильтр `isWorking = false`.
- Прогресс-бар над таблицей (виден при активной проверке).
- Кнопка «Отмена» — `Cancel()`.
- По завершении `test:completed` — перезагрузить текущую страницу и счётчик.

## Контекстное меню

Правая кнопка на строке: Копировать (`Ctrl+C`), Проверить (`Ctrl+R`),
Удалить (`Delete`).

## Горячие клавиши

`useEffect` + `addEventListener('keydown')`:

- `Ctrl/Cmd + R` — проверить выбранные.
- `Ctrl/Cmd + Shift + R` — проверить нерабочие.
- `Ctrl/Cmd + C` — копировать.
- `Ctrl/Cmd + A` — выделить все на странице.
- `Delete` — удалить выбранные (подтверждение, если > 10).

## Фильтры (Toolbar)

- Поиск по host (debounce 300 мс).
- Checkbox «Только рабочие».
- Dropdown «Протокол»: Все / `http` / `socks5`.
- Dropdown «Макс. latency»: Все / <100 / <500 / <1000.

## Обновление при массовой проверке

- Подписка на `test:progress` — обновлять только прогресс, не перечитывать БД.
- По `test:completed` — один раз перечитать текущую страницу и счётчик.
- Не перечитывать весь пул на каждый тик.

## Проверка

- [ ] Страница 100 строк листается без фризов, «Всего N» корректно.
- [ ] Сортировка по latency: серверная, 1 клик — возраст., 2 — убыв.
- [ ] Копирование 100 выбранных: 100 строк в буфере (через Go).
- [ ] Отмена проверки: прогресс-бар исчезает, состояние не сломано.

## Частые ошибки

- **Мерцание при обновлении:** обновлять только по `test:completed`,
  не на каждый `test:progress`.
- **Выбор сбрасывается при пагинации:** хранить выбранные ID вне страницы.
- **Копирование пустого списка:** блокировать кнопку при пустом выборе.
