# UI Source Manager

## Когда использовать

- Реализация страницы «Источники».
- Добавление формы загрузки.
- Отображение списка источников.

## Layout страницы

```
┌──────────────────────────────────────────────────┐
│  [Tabs: URL | Файл | Вручную]                    │
│                                                  │
│  <форма добавления>                              │
│                                                  │
├──────────────────────────────────────────────────┤
│  Источники (N)                                   │
│                                                  │
│  ┌────────────────────────────────────────────┐  │
│  │ Proxifly HTTP              Обновлён 2 мин  │  │
│  │ 152 прокси                                 │  │
│  │ [Обновить] [Удалить]                       │  │
│  └────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────┘
```

## Форма добавления

### Таб URL

- Input для URL (placeholder: `https://raw.githubusercontent.com/...`).
- Input для имени (опционально, по умолчанию — host URL).
- Кнопка «Добавить».
- Валидация: URL должен начинаться с `http://` или `https://`.

### Таб Файл

- Кнопка «Выбрать файл» → Wails `OpenFileDialog` с фильтрами `.txt`, `.json`.
- Отображение выбранного пути.
- Кнопка «Добавить».

### Таб Вручную

- Textarea (10 строк).
- Placeholder с примерами:
  ```
  192.168.1.1:8080
  socks5://10.0.0.1:1080
  ```
- Кнопка «Добавить в пул».

## Список источников

Карточка источника:

- Название (или URL, если пусто).
- Дата последнего обновления (`formatDistanceToNow`).
- Количество прокси.
- Кнопки: «Обновить», «Удалить».

## Действия

- **Добавить:** вызвать соответствующий метод SourceService.
- **Обновить:** повторно загрузить и распарсить, обновить `last_fetched`.
- **Удалить:** подтверждение → удалить источник и связанные прокси
  (или обнулить `source_id`, согласно настройке).

## Эмиссия событий

После успешного добавления/обновления SourceService эмитит `source:fetched`.
Фронтенд перезагружает список источников и пул прокси.

## Проверка

- [ ] Добавление URL Proxifly → источник появляется в списке, прокси в пуле.
- [ ] Добавление файла → путь сохранён, прокси в пуле.
- [ ] Ручной ввод 5 строк → 5 прокси.
- [ ] Обновление источника → `last_fetched` меняется, дубликаты не плодятся.
- [ ] Удаление источника → прокси с этим `source_id` обрабатываются корректно.

## Частые ошибки

- **Файл-диалог не открывается:** проверить, что вызван биндинг Wails,
  а не HTML `<input type="file">`.
- **Дубликаты источников:** не блокировать добавление URL, который уже есть —
  вместо этого предложить «Обновить».
- **Большой файл (>10 МБ):** показывать прогресс загрузки.
