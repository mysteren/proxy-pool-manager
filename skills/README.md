# Skills

Набор скилов для агента DeepSeek v4.1 через Zed IDE.

## Что такое скил

Скил — это директория с файлом `SKILL.md`, содержащим:

- **frontmatter** с полями `name` и `description`;
- **инструкции** для агента: когда и как применять знания.

Агент подгружает скил, когда задача соответствует его описанию.

## Список скилов

| Скил                    | Когда использовать                                |
|-------------------------|---------------------------------------------------|
| `project-bootstrap`     | Инициализация Wails, Tailwind, shadcn/ui          |
| `proxy-source-fetcher`  | Загрузка и парсинг источников                     |
| `proxy-tester`          | Тестирование latency и скорости                   |
| `proxy-storage`         | CRUD, фильтрация, экспорт через SQLite            |
| `ui-theme-manager`      | Светлая/тёмная тема                               |
| `ui-proxy-table`        | Таблица пула прокси                               |
| `ui-source-manager`     | UI управления источниками                         |

## Как использовать

В промпте агенту укажите скил явно:

```
Прочитай skills/proxy-tester/SKILL.md и реализуй тест latency.
```

Или положитесь на авто-подхват — Zed подгружает скилы по описанию.
