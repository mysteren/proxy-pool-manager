# Работа с агентом (Zed + DeepSeek)

## Принципы

1. **Один milestone — одна сессия.** Не смешивать задачи.
2. **Читать документацию перед началом.** Агент обязан открыть нужные
   `docs/*.md` и соответствующий `skills/*/SKILL.md`.
3. **Не выходить за scope.** Если задача в Milestone 3, никаких изменений
   в SourceManager и настройках темы быть не должно.
4. **Проверка после каждой задачи.** Запускать `go test ./...`,
   `npm run test` и `wails3 build` вручную.
5. **Git-коммит после каждой рабочей задачи.**

## Правила для агента

### Делать

- Использовать типы из `internal/models/`.
- Обрабатывать ошибки явно (не `_ = err`).
- Логировать через `log/slog` (Go) и `console.error` (только в dev).
- Эмитить события через `app.Event.Emit` для длительных операций.
- Использовать `context.Context` для отмены.

### Не делать

- Не добавлять системные вызовы (`exec.Command("gsettings", ...)`,
  `iptables`, `nftables`).
- Не блокировать главный поток Go (все тяжёлое — в горутинах).
- Не использовать `time.Sleep` для ожидания (только `context` и каналы).
- Не писать в БД без транзакций при массовых операциях.
- Не хардкодить пути — использовать `github.com/adrg/xdg` (`xdg.DataHome()`),
  не `os.UserConfigDir()` (на Linux это `~/.config`, другой путь).
- Подтверждать работоспособность прокси реальным HTTP-запросом, а не только TCP-connect.

## Контрольные точки

После каждого milestone:

- [ ] `go test ./...` — зелёный.
- [ ] `npm run test` (в `frontend/`) — зелёный (инфра появится в M1/M3).
- [ ] `wails3 build` — успешная сборка.
- [ ] ⛔ Интеграционные/E2E-тесты выключены (`INTEGRATION_TESTS_ENABLED = false`).
- [ ] Ручная проверка сценариев из milestone.
- [ ] Git commit с сообщением `feat: milestone N — <название>`.

## Откат изменений

Если агент сломал что-то в предыдущем milestone:

```bash
git log --oneline               # найти последний рабочий коммит
git reset --hard <commit-hash>  # откатить
```

Перед откатом — сохранить полезные изменения в отдельную ветку:

```bash
git checkout -b wip/milestone-N-broken
git add -A && git commit -m "wip: сохранение до отката"
git checkout main
git reset --hard <commit-hash>
```
