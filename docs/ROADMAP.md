# Roadmap

> ⛔ Интеграционные и E2E-тесты выключены на MVP
> (`INTEGRATION_TESTS_ENABLED = false`, `E2E_TESTS_ENABLED = false`).
> Включим позже — см. `TESTING_STRATEGY.md`.

## Milestone 1 — Bootstrap (1–2 дня)

**Цель:** рабочее Wails-приложение с тёмной/светлой темой и базовым layout.

- [x] Инициализация проекта: `wails3 init -n proxy-pool-manager -t react-ts`
- [ ] Очистка шаблона: переименовать Go-модуль (`changeme`), убрать демо
      (`GreetService`, событие `time`), заполнить `build/config.yml`.
- [ ] Установка Tailwind CSS v4 (через `@tailwindcss/vite`) + shadcn/ui.
- [ ] Настройка layout: sidebar (Прокси / Источники / Настройки) + main area.
      Переключение страниц через `activePage` в Zustand (без роутера).
- [ ] ThemeService в Go: чтение системной темы, эмиссия события.
- [ ] ThemeStore в React: применение класса `dark`, подписка на событие.
- [ ] Проверка: `wails3 dev` запускается, тема переключается по системной.

## Milestone 2 — Источники и парсинг (2–3 дня)

**Цель:** загрузка источников, парсинг, сохранение в SQLite.

- [ ] SQLite: миграции, StorageService с методами вставки/чтения.
- [ ] SourceService: загрузка URL, чтение файла, парсинг строк.
- [ ] Парсер: `ip:port`, `protocol://ip:port`, JSON (`https`→`http`, `socks4` пропуск).
- [ ] UI: SourceManager (форма добавления, список источников).
- [ ] Дедупликация при вставке (UNIQUE constraint).
- [ ] Проверка: добавление источника Proxifly → прокси в БД.

## Milestone 3 — Тестирование latency (2–3 дня)

**Цель:** тест latency, таблица прокси, повторный тест.

- [ ] TesterService: TCP-connect (`DialContext`), HTTP-подтверждение через прокси,
      семафор на `test_concurrency`, таймауты.
- [ ] Эмиссия `test:progress` и `test:completed` (через `application.RegisterEvent`).
- [ ] UI: ProxyTable (серверная пагинация, сортировка, бейджи latency).
- [ ] Toolbar: «Проверить выбранные», «Проверить нерабочие».
- [ ] Прогресс-бар + кнопка «Отмена».
- [ ] Настройка числа одновременных проверок (в Настройках).
- [ ] Проверка: массовая проверка 100 прокси, отмена работает.

## Milestone 4 — Пул рабочих прокси (2 дня)

**Цель:** удобная работа с пулом.

- [ ] Фильтры: «Только рабочие», по протоколу (`http`/`socks5`), по latency.
- [ ] Поиск по host.
- [ ] Серверная пагинация (страницы, общее число, размер страницы).
- [ ] Копирование выбранных через Go `app.Clipboard` (формат `uri` или `host:port`).
- [ ] Экспорт TXT/CSV/JSON (через Wails `SaveFileDialog`).
- [ ] Удаление из пула.
- [ ] Проверка: копирование, экспорт, фильтры, пагинация работают.

## Milestone 5 — Скорость и полировка (3–4 дня)

**Цель:** speed-тест и UX-детали.

- [ ] TesterService: download-тест через прокси, отдельный семафор.
- [ ] Колонка `download_mbps` в таблице.
- [ ] Settings: тема, таймауты, конкурентность, размер download.
- [ ] Горячие клавиши (Ctrl+R, Ctrl+C, Delete).
- [ ] Тосты для успешных операций и ошибок.
- [ ] Проверка: speed-тест 10 прокси, корректные Mbps.

## Milestone 6 — Кроссплатформенность (опционально)

**Цель:** сборка под Windows/macOS.

- [ ] Проверка путей к БД через `adrg/xdg` (Linux/macOS/Windows).
- [ ] Проверка работы `OpenFileDialog` / `SaveFileDialog` на Windows/macOS.
- [ ] Сборка `wails3 build -platform windows/amd64`.
- [ ] Сборка `wails3 build -platform darwin/universal`.
- [ ] Тест на реальных системах (виртуалка / CI).

## Milestone 7 — Продвинутые фичи (по желанию)

- [ ] Определение страны через HTTP-проверку (GeoIP).
- [ ] Группировка прокси в «профили» (наборы для разных задач).
- [ ] Автообновление источников по расписанию.
- [ ] Импорт/экспорт всей конфигурации (источники + пул) в JSON.
- [ ] Системный трей с быстрым доступом к буферу.
