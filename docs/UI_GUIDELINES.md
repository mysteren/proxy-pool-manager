# UI Guidelines

## Принципы

1. **Данные — в центре.** Таблица пула прокси занимает основное пространство.
2. **Минимум кликов.** Частые действия (копировать, тестировать, удалить) —
   в контекстном меню и на панели инструментов.
3. **Никаких модальных окон для простых операций.** Использовать inline-формы
   и тосты.
4. **Никакой блокировки UI.** Все длительные операции показывают прогресс,
   но интерфейс остаётся отзывчивым.

## Темы

- Автоопределение через Wails `app.Env.IsDarkMode()`.
- Подписка на `events.Common.ThemeChanged`.
- Тема хранится в Zustand, применяется классом `dark` на `<html>`.
- Цвета — только через CSS-переменные shadcn/ui (`--background`, `--foreground`,
  `--primary`, `--muted`, `--destructive` и т.д.).
- Ручное переключение в Настройках: `System / Light / Dark`. При выборе
  ручного режима — отписка от системного события.

## Компоненты

### ProxyTable

- **Виртуализация** через `@tanstack/react-virtual` — рендерить только видимые строки.
- **Колонки:**
  - `checkbox` — выбор строк.
  - `host` — текст, моноширинный шрифт.
  - `port` — число.
  - `protocol` — бейдж (http/https/socks4/socks5 — разные цвета).
  - `latency` — цветной бейдж:
    - зелёный `< 150 ms`
    - жёлтый `150–500 ms`
    - красный `> 500 ms`
    - серый `—` (не тестирован)
  - `download_mbps` — число с одним знаком после запятой.
  - `last_checked` — относительное время («2 мин назад»).
- **Сортировка** по клику на заголовок.
- **Контекстное меню** (правая кнопка): Копировать, Тестировать, Удалить.
- **Множественный выбор** через Shift/Ctrl.
- **Индикатор прогресса** над таблицей при массовом тесте, с кнопкой «Отмена».

### Toolbar (над таблицей)

- Поле поиска по host.
- Фильтр «Только рабочие» (чекбокс).
- Фильтр по протоколу (dropdown).
- Кнопки: «Тестировать выбранные», «Тестировать нерабочие», «Копировать выбранные»,
  «Экспорт».

### SourceManager

- Форма добавления источника:
  - Табы: `URL` / `Файл` / `Вручную`.
  - Для URL: input + кнопка «Добавить».
  - Для файла: кнопка открытия диалога (Wails `OpenFileDialog`).
  - Для ручного ввода: textarea + кнопка «Добавить в пул».
- Список источников: карточки с названием, датой обновления, количеством прокси.
- Кнопки на карточке: «Обновить», «Удалить».

### Settings

- Тема: `System / Light / Dark`.
- Таймаут latency (мс).
- Размер скачиваемого файла для speed-теста (байт).
- Конкурентность (число одновременных тестов).
- Формат копирования: `uri` (`protocol://host:port`) или `host:port`.

## Горячие клавиши

| Комбинация          | Действие                      |
|---------------------|-------------------------------|
| `Ctrl/Cmd + R`      | Тестировать выбранные         |
| `Ctrl/Cmd + Shift+R`| Тестировать нерабочие         |
| `Ctrl/Cmd + C`      | Копировать выбранные          |
| `Ctrl/Cmd + A`      | Выделить все                  |
| `Delete`            | Удалить выбранные             |
| `Ctrl/Cmd + ,`      | Открыть настройки             |

## Состояния

- **Пустой пул:** иллюстрация + кнопка «Добавить источник».
- **Загрузка списка:** скелетон-таблица (10 placeholder-строк).
- **Ошибка:** тост с описанием, без модальных окон.
- **Долгая операция:** прогресс-бар + кнопка «Отмена».

## Типографика

- Основной шрифт: `Inter` (через системный fallback).
- Моноширинный: `JetBrains Mono` для host/port/URI.
- Размеры: `text-sm` для таблиц, `text-base` для основного текста,
  `text-lg` для заголовков.
