# UI Guidelines

## Принципы

1. **Данные — в центре.** Таблица пула прокси занимает основное пространство.
2. **Минимум кликов.** Частые действия (копировать, тестировать, удалить) —
   в контекстном меню и на панели инструментов.
3. **Никаких модальных окон для простых операций.** Использовать inline-формы
   и тосты.
4. **Никакой блокировки UI.** Все длительные операции показывают прогресс,
   но интерфейс остаётся отзывчивым.

## Темы

- Автоопределение через Wails `app.Env.IsDarkMode()`.
- Подписка на `events.Common.ThemeChanged`.
- Тема хранится в Zustand, применяется классом `dark` на `<html>`.
- Цвета — только через CSS-переменные shadcn/ui (`--background`, `--foreground`,
  `--primary`, `--muted`, `--destructive` и т.д.).
- Ручное переключение в Настройках: `System / Light / Dark`. При выборе
  ручного режима — отписка от системного события.

## Компоненты

### ProxyTable

- **Серверная пагинация** — фронтенд держит одну страницу (размер настраивается),
  сортировка и фильтрация выполняются на бэкенде. Виртуализация не нужна.
- **Колонки:**
  - `checkbox` — выбор строк.
  - `host` — текст, моноширинный шрифт.
  - `port` — число.
  - `country` / `city` — страна и город выходного узла.
  - `latency` — цветной бейдж:
    - зелёный `< 150 ms`
    - жёлтый `150–500 ms`
    - красный `> 500 ms`
    - серый `—` (не тестирован)
  - `download_mbps` — число с одним знаком после запятой.
  - `distance` — приблизительное расстояние до прокси.
  - `last_checked` — относительное время («2 мин назад»).
- **Сортировка** по клику на заголовок.
- **Контекстное меню** (правая кнопка): Копировать, Тестировать, Удалить.
- **Множественный выбор** через Shift/Ctrl.
- **Пагинация** под таблицей: общее число, размер страницы, переход по страницам.
- **Индикатор прогресса** над таблицей при массовом тесте, с кнопкой «Отмена».

### MTProtoTable

Таблица Telegram-прокси (отдельный пул). Колонки снабжены подсказками:

- `host` / `port` — адрес Telegram-прокси.
- `country` / `city` — страна и город сервера прокси (по его IP, после
  «Определить гео»); `distance` — приблизительное расстояние до него.
- `type` — `mtproto` (собственный прокси Telegram, FakeTLS/obfuscated) или
  `socks` (SOCKS5-прокси с поддержкой MTProto).
- `secret` — секретный ключ из ссылки `tg://proxy`.
- `score` — итоговый балл: надёжность минус пинг и джиттер (сортировка по умолчанию).
- `ping` — средняя задержка рукопожатия за несколько попыток.
- `jitter` — разброс задержки между попытками (стабильность).
- `success` — доля успешных рукопожатий (`successes/attempts`).
- `method` — как ответил прокси: `faketls` или `obfuscated2`.
- `last_checked` — когда проверялся.

### Toolbar (над таблицей)

- Поле поиска по host.
- Статус: Все / Рабочие / Нерабочие / Без статуса.
- Фильтр «Без источника» (чекбокс), фильтр по латентности.
- Кнопки проверки: «Проверить выбранные», «Без статуса», «Нерабочие»,
  «Проверить всё» — у каждой подсказка с пояснением.
- «Определить гео» (только MTProto) — гео по IP сервера, в фоне с прогрессом.
- Действия с пулом: «Очистить статус», удаление непроверенных / нерабочих / всех.
- «Копировать», «Экспорт» (TXT/CSV/JSON).

### SourceManager

- Форма добавления источника:
  - Табы: `URL` / `Файл` / `Вручную`.
  - Для URL: input + кнопка «Добавить».
  - Для файла: кнопка открытия диалога (Wails `OpenFileDialog`).
  - Для ручного ввода: textarea + кнопка «Добавить в пул».
- Список источников: карточки с названием, датой обновления, количеством прокси.
- Кнопки на карточке: «Обновить», «Удалить».

### Settings

- Тема: `System / Light / Dark`.
- Таймаут проверки (мс).
- Размер скачиваемого файла для speed-теста (байт).
- Число одновременных проверок (конкурентность).
- Подтверждать работоспособность HTTP-запросом + URL проверки.
- Гео: срок хранения кэша (дней) и кнопка «Сбросить гео-кэш».
- Формат копирования: `uri` (`protocol://host:port`) или `host:port`.

## Подсказки (Hint)

- Компонент `frontend/src/components/ui/hint.tsx` — всплывающая подсказка
  без сторонних зависимостей. Позиционируется через `position: fixed` по
  координатам триггера, поэтому не обрезается в таблицах с `overflow`.
- Срабатывает по наведению и по фокусу (доступность с клавиатуры).
- Заголовки колонок и параметры настроек поясняются **на русском**: что это за
  величина, как считается и что означает (пинг, скорость, расстояние, оценка
  MTProto, джиттер, надёжность и т.д.).
- Для обёртки кнопок используется режим `plain` (без пунктирного подчёркивания)
  и `focusable={false}`.

## Горячие клавиши

| Комбинация          | Действие                      |
|---------------------|-------------------------------|
| `Ctrl/Cmd + R`      | Тестировать выбранные         |
| `Ctrl/Cmd + Shift+R`| Тестировать нерабочие         |
| `Ctrl/Cmd + C`      | Копировать выбранные          |
| `Ctrl/Cmd + A`      | Выделить все                  |
| `Delete`            | Удалить выбранные             |
| `Ctrl/Cmd + ,`      | Открыть настройки             |

## Состояния

- **Пустой пул:** иллюстрация + кнопка «Добавить источник».
- **Загрузка списка:** скелетон-таблица (10 placeholder-строк).
- **Ошибка:** тост с описанием, без модальных окон.
- **Долгая операция:** прогресс-бар + кнопка «Отмена».

## Типографика

- Основной шрифт: `Inter` (через системный fallback).
- Моноширинный: `JetBrains Mono` для host/port/URI.
- Размеры: `text-sm` для таблиц, `text-base` для основного текста,
  `text-lg` для заголовков.
