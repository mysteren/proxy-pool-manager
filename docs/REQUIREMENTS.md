# Требования

## Область применения

Приложение собирает прокси из источников, проверяет их на работоспособность
и формирует удобный пул рабочих прокси. Пользователь копирует нужные прокси
и использует их в своих приложениях (браузер, `yt-dlp`, `curl`, `wget`).

**Приложение не устанавливает системный прокси и не управляет маршрутизацией.**

## Нефункциональные требования

- **Платформа:** Linux (GNOME, KDE), с перспективой Windows/macOS.
- **Производительность:**
  - Запуск приложения ≤ 2 сек.
  - Потребление памяти в простое ≤ 150 МБ.
  - Число одновременных проверок настраивается (по умолчанию 50).
  - Пул проверяется реальным HTTP-запросом через прокси: честность важнее скорости.
    Время проверки 1000 прокси зависит от конкурентности и таймаутов.
  - UI отзывчив при 10 000 прокси за счёт серверной пагинации
    (фронтенд держит одну страницу, а не весь пул).
- **Надёжность:**
  - Все сетевые операции с таймаутами.
  - При падении одного теста — остальные продолжаются.
  - Отмена массового теста завершает все активные горутины.
- **UX:**
  - Горячие клавиши: `Ctrl/Cmd + R` — повторный тест, `Ctrl/Cmd + C` — копировать, `Delete` — удалить.
  - Уведомления-тосты для успешных операций и ошибок.

## Ограничения (вне области первого этапа)

- ❌ Установка системного прокси (GSettings, KDE, env vars).
- ❌ PAC-скрипты.
- ❌ Per-app proxy (nftables, cgroups, ptrace).
- ❌ TUN-режим, sing-box, mihomo.
- ❌ Браузерные расширения.
- ❌ Синхронизация между устройствами.

## Форматы данных

### Входные (источники)

- `socks5://ip:port` — явное указание протокола.
- `ip:port` — строка без схемы считается SOCKS5.
- JSON Proxifly: `{"ip": "...", "port": 1080, "protocols": ["socks5"], "country": "US"}`.
- Строки с другими протоколами (`http://`, `https://`, `socks4://`) пропускаются.

### Протоколы (MVP)

Приложение работает только с двумя типами: **SOCKS5** (раздел «SOCKS5») и
**MTProto / tg-socks** (раздел «MTProto»). Обычные HTTP(S)-прокси на этом этапе
не поддерживаются.

- Из обычных прокси принимается только `socks5` (`socks5h` нормализуется в `socks5`).
- `http`/`https`/`socks4` и неизвестные протоколы пропускаются
  (в частности `socks4`: Go `x/net/proxy` поддерживает только SOCKS5).

### Выходные (копирование / экспорт)

- TXT: `protocol://host:port` — по одному на строку.
- CSV: `host,port,protocol,latency_ms,download_mbps,country`.
- JSON: массив объектов с полями из БД.
